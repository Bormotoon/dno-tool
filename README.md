# dno-tool

Управляйте компьютерами из одного окна: выполняйте команды на группе устройств, передавайте файлы, проверяйте доступность и подключайтесь к рабочим столам.

DNO Tool помогает в повседневной работе с компьютерными классами и рабочими станциями. Приложение доступно для Windows и МОС Linux. Команды выполняются через SSH; готовые задачи ориентированы прежде всего на Linux. Возможность выполнить конкретную задачу зависит от системы и установленных программ на удалённом компьютере.

## Что можно делать

- **Выполнять команды на нескольких компьютерах.** Выберите устройства и задачу из библиотеки, следите за результатом каждого компьютера и отвечайте на запросы команды прямо в окне вывода.
- **Передавать файлы.** Двухпанельный SFTP-командер позволяет работать с локальными и удалёнными папками; передачу файлов можно включать в многошаговые задачи.
- **Работать с экранами.** Миниатюры Veyon или VNC помогают видеть состояние рабочих мест, удалённый рабочий стол — подключаться для помощи пользователю.
- **Находить устройства и проверять сеть.** Сканер хостов, пингер и карта сети доступны в меню «Инструменты».
- **Настраивать доступ.** Мастер помогает добавить устройства, загрузить команды, подготовить SSH-ключи и настроить Veyon или VNC.
- **Работать с видео.** Просматривайте и записывайте IP-камеры, обрезайте и объединяйте записи во встроенном видеоредакторе, добавляйте подписи и экспортируйте готовое видео.
- **Управлять через браузер и объединять площадки.** Встроенный веб-сервер даёт доступ без установки приложения на клиенте; ноды подключают устройства других экземпляров DNO Tool.
- **Настроить рабочее окно под себя.** Соберите панели с кнопками часто используемых команд.

## Установка

### Windows

1. Откройте [последний релиз](https://github.com/xp9k/dno-tool/releases/latest).
2. Скачайте архив `dno-tool-<версия>-windows.zip` и распакуйте его в удобную папку.
3. Запустите `dno-tool.exe`. Python устанавливать не нужно.

### МОС Linux

1. На странице релиза выберите RPM-пакет для вашей версии МОС — 12 или 13 — и архитектуры x86_64.
2. Откройте терминал в папке загрузки и установите выбранный файл, подставив его имя:

   ```bash
   sudo dnf install ./имя-скачанного-пакета.rpm
   ```

3. Запустите DNO Tool из меню приложений или командой `dno-tool`.

Библиотека команд поставляется отдельно от программы. Её можно загрузить через мастер настройки или импортировать из файла `commands.json`. Для работы без интернета заранее скачайте архив `dno-tool-commands-<версия>.zip` из релиза и распакуйте его.

## Первые шаги

1. **Подготовьте доступ к одному компьютеру.** Нужны его адрес, работающий SSH-сервер, логин и пароль либо SSH-ключ. Для административных действий у пользователя должны быть соответствующие права.
2. **Пройдите мастер настройки.** Он открывается автоматически, если ещё нет списков устройств и команд. Повторно открыть его можно через **Помощь → Инструменты → Мастер настройки**.
3. **Добавьте устройство и учётные данные.** «Связка» — сохранённая пара логин/пароль; её можно назначить нескольким компьютерам.
4. **Загрузите библиотеку команд** на шаге «Команды» мастера или импортируйте свой файл. Сохраните настройки кнопкой **Готово**.
5. **Проверьте работу на одном устройстве.** Отметьте его галочкой, выберите задачу просмотра сведений о системе, прочитайте её описание и нажмите **Выполнить**. Двойной щелчок по результату открывает вывод.
6. **Добавляйте остальные компьютеры**, когда проверите подключение и выбранную задачу. Галочки определяют, на каких устройствах она будет выполнена.

Для SSH-команд и передачи файлов Veyon/VNC не нужны. Для просмотра экранов сервер удалённого доступа настраивается отдельно. Мастер предлагает kmsvnc, x11vnc и KRFB: выбор зависит от графического сеанса и видеокарты. Ограничения и порядок настройки описаны в руководстве.

## Полезно знать

- **Статус «онлайн» не проверяет пароль.** Он показывает доступность сетевого подключения; правильность учётных данных проверяется при входе.
- **Программа и команды обновляются отдельно.** Обновление приложения не заменяет вашу библиотеку. Перед импортом изменений можно экспортировать текущие команды через **Файл → Задачи**.
- **Данные хранятся в профиле пользователя.** В Windows это `%USERPROFILE%\.dno-tool`, в Linux — `~/.dno-tool`. Экспорт устройств и команд доступен в меню **Файл**; он не заменяет резервную копию настроек и ключей.
- **Запись камер требует работающего приложения.** После полного выхода запись прекращается и при новом запуске сама не возобновляется. Старые записи автоматически не удаляются.
- **Проект видеоредактора и готовое видео — разные файлы.** Сохраните проект, чтобы продолжить монтаж, и выполните экспорт, чтобы получить видео. Исходные записи нужно хранить вместе с проектом отдельно.
- **Медиадвижок включён в готовые сборки.** Его проверка доступна через **Помощь → Инструменты → FFmpeg**. Для просмотра камеры во внешнем плеере этот плеер устанавливается отдельно.

Подробные инструкции, настройки и помощь при ошибках — в [руководстве пользователя](https://htmlpreview.github.io/?https://raw.githubusercontent.com/xp9k/dno-tool/main/docs/readme.html). Его также можно открыть локально: [docs/readme.html](docs/readme.html).
